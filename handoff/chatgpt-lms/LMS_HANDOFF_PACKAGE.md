## SECTION 1 — PROJECT OVERVIEW

### Project Name
**JLPT N5 → N1 Japanese Language Learning System**
*日本語大学 (Nihongo Daigaku)*

### Project Goal
Deliver a complete, structured Japanese language curriculum that takes a learner from absolute beginner (N5) to advanced fluency (N1 + native-level communication), integrating JLPT exam preparation with real-world communicative competence. The curriculum is optimized for an international student **living in Japan**, targeting not only exam passage but genuine fluency.

### Target Audience
- **Primary:** International students enrolled at Japanese universities
- **Secondary:** Working professionals living in Japan targeting N2/N1 for career advancement
- **Profile characteristics:**
  - Living in Japan (daily immersion environment available)
  - English + multilingual background (Myanmar, Thai, basic Chinese known)
  - Existing basic Japanese knowledge (pre-N5 to low N5)
  - Target: JLPT N1 + natural communication ability

### Learning Outcomes (Course-Level)

Upon completing the full curriculum, the learner will be able to:

1. Pass the JLPT N1 examination
2. Read Japanese newspapers, novels, and documentation without a dictionary
3. Watch anime and Japanese TV without subtitles
4. Communicate naturally in casual and formal registers
5. Function professionally in a Japanese workplace using keigo
6. Understand and use contemporary youth slang and internet Japanese
7. Demonstrate cultural competency in Japanese social and workplace contexts
8. Think and process information directly in Japanese without English translation

### Curriculum Structure

The curriculum is organized into **5 levels** (N5 → N1), each containing **4 modules** of approximately **20 lessons** each.

| Level | Modules | Approx. Lessons | Target Hours |
|-------|---------|-----------------|--------------|
| N5 | 4 | 80 | 150 hrs |
| N4 | 4 | 80 | 150 hrs |
| N3 | 4 | 80 | 200 hrs |
| N2 | 4 | 80 | 250 hrs |
| N1 | 4 | 80 | 300 hrs |
| **Total** | **20 modules** | **~400 lessons** | **~1,050 hrs** |

In addition to the 5 main levels:

- **Foundations Track** (pre-N5): Hiragana, Katakana, Learning Science, Fluency System Theory
- **Mock Exam Series**: One full mock exam per level (N5–N1)
- **Supplementary Paths**: Slang University, Business Japanese, Culture Guide, Media Immersion (cross-level enrichment modules)

## SECTION 7 — DESIGN RULES

### Formatting Rules

1. **Lesson length:** Each lesson targets 80–120 lines minimum of instructional content. Total file length typically 300–600 lines.
2. **Vocabulary count per lesson:** 10–35 items, grouped by topic when multiple semantic groups are present (see L2: Numbers / Time / Demonstratives as 3 subsections).
3. **Kanji count per lesson:** 3–12 kanji. N5 lessons introduce 5–12; N1 lessons may introduce 1–3 very complex characters.
4. **Grammar points per lesson:** 2–3 points. Never 1 (too thin); never 4+ (cognitive overload).
5. **Example sentences per grammar point:** Minimum 5 per point, numbered continuously within the lesson.
6. **Furigana:** Always provided in vocabulary tables and the first appearance of new kanji in example sentences.
7. **Register labeling:** All example sentences and dialogues are labeled: `formal` / `neutral` / `casual` / `written` / `internet only` etc.
8. **Real-world anchoring:** Every listening scenario and at least one homework task must be grounded in the learner's actual environment (living in Tokyo, using trains, convenience stores, university).
9. **"What natives know" notes:** At least one callout per lesson highlighting the gap between textbook form and natural speech.
10. **Japanese script:** All Japanese text uses the correct mix of hiragana, katakana, and kanji appropriate to the lesson level. N5 lessons use primarily hiragana + lesson kanji. N1 lessons use full kanji density.

### Quiz Rules (for LMS system to build from raw content)

1. **Question types per lesson:** Multiple choice · Fill in the blank · Matching · Translation (4 types, all required).
2. **Minimum questions:** 10 per lesson quiz (3 MC + 3 FiB + 3 Matching + 1 Translation minimum).
3. **Answer keys:** Always included in source .md files, clearly labeled.
4. **Distractors for MC:** 4 options (a/b/c/d). Distractors should be plausible — wrong for a clear linguistic reason, not random.
5. **Translation direction:** Both EN→JP and JP→EN are required.
6. **Quiz placement in source file:** After Writing Practice, before Flashcards.
7. **⚠️ KNOWN GAP — L2:** The quiz section in N5_M1_L2 was replaced by Practice Exercise Sets (A/B/C). The LMS system must convert Exercise Sets A/B/C into a formal quiz bank for L2. The answers are present and correct.

### Flashcard Rules (for LMS/Anki system)

1. **Format:** `Q: [prompt] | A: [answer]` — one card per line.
2. **Minimum cards per lesson:** 10 (typically 12–16).
3. **Card types included:** Vocabulary (reading + meaning), kanji (readings + meaning + stroke count), grammar (pattern → explanation).
4. **Placement in source file:** After Quiz, before Homework.
5. **⚠️ KNOWN GAP — L2:** Flashcard section is **absent** from N5_M1_L2. The LMS system must generate the L2 flashcard bank using the vocabulary (34 items) and kanji (12 entries) from the lesson content. Raw material is all present in the file.

### Assignment Rules

1. **Homework structure:** 3 sections — Review Tasks / Memorization Tasks / Practical Usage Tasks.
2. **Practical tasks:** Must be executable by someone living in Japan (no virtual-only tasks).
3. **Review tasks:** Always include at least one oral/reading-aloud task.
4. **Memorization tasks:** Always include a writing task (stroke practice for kanji).

### Assessment Rules

1. **End-of-module assessment** (L20 of each module): Cumulative. Covers all vocabulary, kanji, and grammar from L1–L19.
2. **Mock exams** (M4 of each level): Full JLPT-format exam. Sections mirror actual JLPT: 言語知識 (vocabulary/grammar) + 読解 (reading) + 聴解 (listening).
3. **Passing threshold:** 60% overall, 40% minimum per section (mirrors real JLPT scoring logic).
4. **Mock exam length:** N5 mock = 110 min / N4 = 125 min / N3 = 140 min / N2 = 155 min / N1 = 170 min.
